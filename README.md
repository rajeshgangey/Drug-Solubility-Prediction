# Drug Solubility Prediction — Demo

**Tech:** Pandas, scikit-learn Random Forest Regression, Streamlit.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

This project demonstrates a regression pipeline from molecular-property-style inputs. The target values are arbitrary teaching examples, not measured solubility. Do not use the predictions for scientific or pharmaceutical decisions. A serious version should use a documented dataset with units, standardized assay conditions, appropriate splits, and error metrics.
